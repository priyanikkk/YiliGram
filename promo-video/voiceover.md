# Озвучка YiliGram

Текст диктора по сценам. **«Субтитры»** — как написано в кадре (src/content.ts → `VOICEOVER`).
**«Диктор»** — то же самое, но так, чтобы русский синтезатор правильно произнёс латиницу.
`npm run voiceover` (или `.venv/bin/python scripts/voiceover.py`) собирает `public/voiceover.wav` из колонки «Диктор»
голосом Piper `ru_RU-dmitri-medium`. Свою запись можно положить вместо `public/voiceover.wav`: реплики должны
начинаться в указанные секунды от начала сцены (начала сцен — в `src/config.ts`).
